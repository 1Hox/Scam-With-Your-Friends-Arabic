## شغّلها بثلاث خطوات

1. شغّل نسخة Steam من اللعبة مرة واحدة، ثم أغلقها.
2. افتح **Scam.Arabic.exe**. إذا ما اكتشف اللعبة، اختر مجلدها.
3. اضغط **تعريب وتشغيل اللعبة**. أول تجهيز ينزّل متطلبات الصوت تلقائيًا، ثم يفتح اللعبة.

الشخصيات الست وصورها تأتي مع اللانشر، بدون نسخ ملفات يدويًا: **محسن الحفراوي، كنق النظيم، جسوم ساطوره، حمود الفحل، بسيط نجم، وشفيق**.

## تحتاج

- اللعبة الأصلية على Steam، الإصدار المدعوم **build 26261495**.
- كرت **NVIDIA يدعم CUDA** لتشغيل النطق والتعرّف المحليين. جرى الاختبار على RTX 4070 بسعة 12 GB؛ لا توجد نتيجة مؤكدة لكل كرت.
- إنترنت ومساحة لتنزيل نماذج الصوت بعدة جيجابايت أول مرة. لا تحتاج تثبيت Python يدويًا أو مفتاح خدمة صوت.
- حوار الشخصيات ومعلومات العميل ما زالا يستخدمان خدمة اللعبة الأصلية واتصالها بالإنترنت.

## وش يضيف؟

- نص عربي واضح، وأرقام مستقلة يسهل نسخها.
- نطق وتعرّف عربيان محليان، مع كلمات خليجية وتلميحات نطق.
- افتتاحيات متناسقة مع الاسم؛ الشخصيات المعروفة تحتفظ ببلدانها، والشخصيات الخليجية بخلفياتها.
- تنبيهات أمان داخل اللعبة بصياغة واضحة وأزرار تشرح الإجراء.
- خيارات للاحتفاظ بالتسجيلات، أو حذفها عند الخروج، أو تعطيل حفظها.
- زر تحديث في اللانشر. **إلغاء التعريب** يرجّع الملفات من النسخة الاحتياطية المحلية.

النطق واللهجة قد يخطئان في بعض الكلمات؛ لا تدّعي النسخة دقة أو طبيعية مثالية. هذه إضافة مستقلة غير رسمية، ولا تفتح اشتراكات اللعبة أو مزايا VIP المدفوعة.
